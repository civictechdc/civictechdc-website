How this was made. On 24 July 2026, a swarm of 97 AI agents (one per repo) read each repository's README and metadata and scored the underlying idea 1–5 for revival potential. This is a scouting report on ideas, not a code review — treat every assessment as a lead to verify, not a verdict. Stall reasons are inferred from repo evidence unless stated otherwise. This public version is curated: private repositories, empty placeholders, mirrors of external tools, and internal infrastructure repos are omitted from the full scan.

Scoring. ★★★★★ = an idea that deserves a second life · ★★★ = solid but niche or partly superseded · ★ = one-off or dead end. Tiers: Top and Worth a look are dormant-but-revivable; Rest is logged for completeness; Active repos were pushed within the last year — join those instead of starting fresh.
